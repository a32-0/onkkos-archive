# specs/

The constitution, the eleven specs, the plan and the tasks. They were written
before this repository existed, in the private repository where the app was
first built and its product reasoned out. They travelled here unchanged, so
they speak from there:

- **"Today", "the code", "this repository"** and every path under `src/lib/` or
  `src/components/` mean that first build, not this repository.
- **"Divergences from the code"** in each spec lists where that first build
  differed from the spec. This repository is built from the specs, so those
  differences never reach it.
- **"Does not travel"** names what stayed behind in the first build.

The plan's [part 1](plan/01-repository.md) maps each of those paths to its
place here, and each task names the files it brings.
