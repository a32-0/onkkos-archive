# docs/specs/

What the app is and what each screen does. These pages are current: when the
app changes, its spec changes first (see [`maintaining.md`](../maintaining.md)).

- [`00-constitution.md`](00-constitution.md) holds the rules every other page
  answers to.
- `01` to `13` are the specs, one per screen or service, each written against
  its Figma frames: what it shows, where its data comes from, and how to check
  that it works.

How the app was planned and built, part by part and task by task, is in
[`../history/`](../history/README.md).
