# docs/history/

How the app was built, kept as a record. Nothing here is maintained: each page
describes the project as it stood when it was written, and some of it no
longer holds. What is true today is in [`../specs/`](../specs/README.md) and
the other pages of [`docs/`](../README.md).

The app was built in phases, from 2026-10-04 to 2026-10-24, in a fixed order:
the constitution, the Figma frames, the specs, a plan, small tasks, and the
code last. Development ended with T-48; later changes follow
[`maintaining.md`](../maintaining.md) and are not cut into tasks.

- [`spec-driven-order.md`](spec-driven-order.md): the order the work followed,
  and why.
- [`public-release.md`](public-release.md): the decisions on the way to the
  public release, with the measurements that settled them, up to the move to
  an app on the player's machine.
- [`plan/`](plan/): the plan in six parts: the repository's tree, the
  architecture, the design system, the deployment, the documents and the
  roadmap.
- [`tasks/`](tasks/README.md): the 48 tasks, each with what it built and how
  it was checked. Every commit of the build names its task.
